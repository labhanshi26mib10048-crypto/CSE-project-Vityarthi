# Project Statement

## Problem Statement

Students often have several academic and personal tasks to manage. A simple task management system can help users record tasks, organize them by category and priority, and track their completion status.

## Scope

The project is a command-line To-Do List Management System developed using Python. It stores task information in a CSV file and provides basic task management and reporting features.

## Target Users

The main target users are students who want a simple way to manage their academic and personal tasks.

## High-Level Features

1. Add a task
2. View tasks
3. Edit a task
4. Complete a task
5. Delete a task
6. Store tasks in a CSV file
7. Validate user input
8. Generate a simple task report
