# CSE-project-Vityarthi
To-Do List management system is a simple python based program designed to help students manage their daily academic and personal tasks. The system provides an easy way to add, view, edit, complete and delete tasks.
To-Do List Management System

1. Project Overview
This is a beginner-friendly Python project for managing daily tasks.
The project allows a user to:
Add tasks
View tasks
Complete tasks
Edit tasks
Delete tasks
View a task report
Tasks are stored permanently in a CSV file.

2. Functional Modules
Module 1 - Task Management
Create, view, edit, complete and delete tasks.
Module 2 - Validation
Checks empty task names, valid priorities and valid task numbers.
Module 3 - Storage
Reads and writes tasks using a CSV file.
Module 4 - Reporting
Shows total, completed, pending and priority/category information.

5. How to Run
Install Python 3.
Put all files in the same folder.
Open the folder in VS Code.
Open the terminal.
Run:
python main.py

6. Testing
Run:
python test_project.py
The program should display:
Basic tests passed.
